# Native application output schema 4

The driver uses the public `fPLS` and `fPCR` models from fdaPDE-cpp. It performs functional mean centering before the model fit. `fit_seconds` covers the complete model fit, including fPCR score projection and prefix regressions; model diagnostic serialization belongs to `output_seconds`.

`fpls_loading_gcv.csv` retains complete candidate curves for components whose selected loading lambda is a grid endpoint. The six columns are `component`, `lambda`, `edf`, `gcv`, `selected_by_fit`, and `grid_minimum`. `grid_minimum` replaces schema 3's `replay_minimum`: both EDF and GCV now come from the actual model calibration, with no diagnostic refit or trace re-estimation. Selection flags use candidate positions, so duplicate lambda values do not mark multiple rows as selected. The telemetry source is `calibration_evaluations_saved_during_fit`; `diagnostic_refits` is zero. Fixed calibration has no GCV curve.

`fpca_gcv.csv` preserves its columns (`component`, `lambda`, `edf`, `gcv`, `selected_by_fit`) and records the public model's saved calibration evaluations. `gcv_probes` and `gcv_seed` control the same estimates used to select each component. `fpca_implementation` is now `public_fdaPDE_fPCR_with_explicit_edf_control`. The public GCV path uses floating-point residual degrees of freedom `m - edf`, preserving this application's previous explicit-EDF formula. Probe count and deterministic seed remain explicit; the old simulation fPCA path instead used default EDF settings and truncated residual degrees of freedom. Scalar application fits are expected to agree within floating-point roundoff.

For a response with q columns, `y_hat_hH.csv` and `beta_coefficients_hH.csv` each have q columns, and `y_space_directions.csv` / `y_loadings.csv` have q rows and H columns. `y_latent_scores.csv` contains each score's contribution to the full OLS fit: n subjects by H*q columns, ordered by component, then response. Telemetry lists the one-based component and response for every column. A scalar response retains its previous n-by-H layout. `response_diagnostics.csv` reports `component`, `response`, `sse`, and `mse` for every prefix and response.

R wrappers validate this schema and the shape of every response prediction and regression coefficient. General evaluation reports per-response errors. CTRL/SCHZ separation metrics and the intrinsic classification slider have a defined scalar-response interpretation; multivariate evaluation explicitly marks separation as unavailable, and the classification slider rejects multiple responses.
