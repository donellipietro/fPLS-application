# Application figure assets

`panels/` contains only the two Affinity-ready panel folders:

- `A_latent_scores/`, generated by `scripts/A_latent_scores.R`;
- `A_slider/`, generated by `scripts/A_slider.R` and `scripts/A_slider.py`.

Set `FPLS_RESULTS` when the ignored application result store is not linked as
`results/`; `A_slider.R` also needs `PVPYTHON` set to the ParaView executable.
